# 人生原则文件构建官

一句话让 AI 帮你把自己整理清楚，产出一份可以长期使用的《人生原则文件》。

---

## 这是什么

一个 WorkBuddy / Claude / ChatGPT 都能用的 Skill。

它只做一件事：**通过一轮一轮的提问，引导你回答、筛选、收敛，最后产出一份属于你自己的《人生原则文件》。**

这份文件会写清你是谁、你经历过什么、你会什么、你信什么、你想帮谁、你凭什么是我。

做完之后，把它交给任何 AI 当背景材料，效果和空着手问完全是两回事。不管是拍短视频、写公众号、做个人 IP，还是请 AI 帮你判断一个职业或生意选择，先把这份文件给它。

**交付物只有一个文件：`人生原则文件.md`。**

## 安装

### 方式一：一句话安装（最省事，推荐）

把本仓库地址发给 WorkBuddy，然后说：

> 安装这个 skill

它会自己读取仓库内容并注册，不用你下载、不用你找目录。

仓库地址：

```
https://github.com/{OWNER}/life-principles-builder
```

### 方式二：直接用，不安装

在任意 AI 对话里，把本仓库 `SKILL.md` 的全部内容复制粘贴进去，然后说：

> 按这个流程给我做访谈

缺点是新开对话要重新贴一次，适合先试试效果。

### 方式三：手动放进技能目录

下载本仓库，把整个 `life-principles-builder` 文件夹放到：

| 系统 | 路径 |
| --- | --- |
| Windows | `C:\Users\你的用户名\.workbuddy\skills\` |
| macOS / Linux | `~/.workbuddy/skills/` |
| Codex | `~/.codex/skills/` |

放好后重启工具，让技能列表重新加载。

## 怎么用

安装完成后，跟 AI 说一句话即可启动：

> 帮我做我的人生原则文件

这些说法也能触发：

- 帮我整理一下我的人生经历
- 把我的背景整理一下，以后好喂给 AI
- 我想做个人 IP，但不知道自己有什么
- 梳理一下我的个人定位和背景档案

### 流程

1. AI 先说明一共十个阶段、大概几轮，然后从第一阶段的 6-8 个问题开始问。
2. 你答完，AI 给一份**阶段摘要**，把内容分成五类：已确认事实、你的观点、AI 的推断（待确认）、待补充、表达边界。
3. 你确认没问题，进入下一阶段；有问题当场改。
4. 十个阶段走完，AI 把全部内容整理成一份 `人生原则文件.md` 写到你本地。

**大约 10 轮对话。** 一轮聊一个主题。答不上的直接说"跳过"，AI 会记进待补充清单，不会追着问。

### 三种模式

| 模式 | 什么时候用 | 轮次 |
| --- | --- | --- |
| 标准模式 | 默认，想一次做扎实 | 10 轮 |
| 快采模式 | 先搭个雏形，以后再补 | 3 轮 |
| 续写模式 | 已有文件，补空缺或加新经历 | 按缺口定 |

想快就直接说："用快采模式，三轮搞定。"

## 十个阶段

| 阶段 | 主题 | 问什么 |
| --- | --- | --- |
| A | 基本盘与人生时间线 | 出生、地域、家庭、现状、时间与钱的约束 |
| B | 职业履历与关键项目 | 每段经历拆成可引用的事实 |
| C | 能力资产与优势分析 | 找到你自己低估的那部分 |
| D | 至暗时刻与转折点 | 困境怎么变成别人拿不走的素材 |
| E | 价值观与人生原则 | 提炼你真正在用的原则 |
| F | 使命、愿景与目标 | 找到比赚钱更持久的动力 |
| G | 目标人群与真实需求 | 你想帮谁，凭什么帮 |
| H | 个人定位与人设 | 我是谁、写给谁、凭什么是我 |
| I | 产品方向与变现路径 | 能力怎么变成别人愿意付费的东西 |
| J | 表达风格、事实边界与素材库 | 你怎么说话、什么不能说、手上有什么料 |

其中三个阶段会要求你**做选择**：能力收敛到核心 3 项、原则收敛到 5-8 条、话题收敛到 3 个支柱。这一步是这份文件真正好用的关键——文件的价值不在长得全，在于够准。

## 产出长什么样

十二章结构，头部带元信息和一段"给 AI 的读取说明"：

```
零、一句话自述与人生使命
一、基本盘（现状快照）
二、人生时间线
三、职业履历与关键项目
四、能力资产与优势分析
五、至暗时刻、转折点与代价
六、核心人生原则
七、目标人群与真实需求
八、个人定位与人设
九、产品方向与变现路径
十、表达风格与事实边界
十一、高光时刻与素材库
十二、待补充与迭代
```

所有信息都标注状态：确认过的事实、你自己的观点、AI 的推断（待确认）、还没补上的空缺。AI 推断的部分不会被当成事实使用。

## 几条说明

**它不会编造你的经历。** 你没说过的，它不会替你想象；缺的地方标 `[待补充]`。你提到别人的故事、对标的账号，它只会放进参考区，不会写进你的经历。

**敏感内容可以不答。** 涉及失败、家庭、金钱、健康的问题都可以跳过。愿意答但不想公开的，会标注公开范围，后续任务不会引用。

**它不做市场调研、不出定位方案。** 所有分析都写进这一份文件里，不会额外产出别的报告——它只有一个交付物。

**它是活的。** 以后有新经历、新想法，跟 AI 说一句，它会判断属于哪一章，提出更新建议，你确认后写进去，版本号加 0.1。
